--- ARCHITECTURAL & MODULATION SPECIFICATIONS ---
1. Constellation Used:
   - Constellation: QPSK (Quadrature Phase Shift Keying), M = 4.
   - Mapping: 2 bits per symbol (1 bit in-phase I, 1 bit quadrature Q).
   - Gray Coded symbols: x = ((1 - 2*b_I) + j*(1 - 2*b_Q)) / sqrt(2).
   - Constellation points: (+1+j)/sqrt(2), (+1-j)/sqrt(2), (-1+j)/sqrt(2), (-1-j)/sqrt(2).

2. Head Output Type:
   - The MIMO Detection head outputs CONTINUOUS SYMBOLS (soft real/imag components in R^{B x 64 x 16}).
   - It does NOT output raw binary bits or unnormalized logits.
   - The architecture combines a Linear MMSE base symbol estimate with a learned neural residual:
       base_syms = [z_mmse_real, z_mmse_imag]
       out_det = base_syms + delta_det

3. BER Calculation Stage (Before or After Slicing?):
   - BER is computed strictly AFTER SLICING (hard-decision thresholding).
   - Continuous real/imag symbol outputs are sliced at zero threshold:
       b_pred = 1 if out_det < 0.0 else 0
       b_true = 1 if target < 0.0 else 0
   - Bit Error Rate (BER) = sum(b_pred != b_true) / total_bits.
   - Symbol Error Rate (SER) is an error if either the I or Q bit is incorrect.
